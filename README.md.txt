URL Shortener
A Python-based URL Shortener that converts long URLs into short and manageable links. This project demonstrates backend logic, unique ID generation, and URL mapping concepts.

Features
- Shortens long URLs
- Generates unique short codes
- Redirects users to original URLs
- Simple and lightweight
- Beginner-friendly implementation
- Easy to customize

Technologies Used
- Python 3
- Flask
- Dictionaries / Database
- Random & String Modules

How It Works
1. User enters a long URL.
2. The system generates a unique short code.
3. The short URL is stored and mapped to the original URL.
4. When accessed, the short link redirects to the original website.
